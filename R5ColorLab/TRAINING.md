# v4.5 色卡与训练输入更新

默认数据集为`v4.5-sony100mp-5300k-sim-center5-20261029`。Sony 5300K拍摄WB由Bayer反向补偿，完整99,372块纯模拟入口已独立验证。新目标须由v4.5 RAW重新导出；旧v4任务和目标继续绑定原始版本。训练/留出/最终网格/评估统一为中心横向5点均值，9点仅保留作验证。

Adobe RGB目标按内嵌ICC，以LittleCMS浮点输入/输出、禁用优化查表、相对色度、无黑点补偿，先转换每个点再平均；中途不转8位。最终整数输出验收及已记录的1块PT微差详见README。参数平滑30、输出连续性30、最终网格直接拟合目标和原有GPU策略保持。

以下为连续性方案及现有v4正式滤镜的来源记录。

# 当前正式高精度训练方案

本方案对应2026-10-28正式12滤镜批次，全部从原厂起点重新训练；不复用旧NC的拟合参数。完整设置见[training_options.json](../filters/FUJ_12_continuity30/training_options.json)，成品与回执见[滤镜目录](../filters/FUJ_12_continuity30/README.md)。

| 设置 | 正式值 |
| --- | --- |
| 速度优先 | 关闭 |
| 每阶段评估上限／起点 | 2000／12 |
| 动态权重轮数 | 8 |
| Gamma与CC1/block13交替 | 3轮 |

| 第129点Gamma导出端点 | 131071 |
| 正式训练后端／并发 | Apple Metal/MPS／2 |

合成色卡为11648×8736、99,372个32×32色块；目标TIFF/JPG保留几何，支持RGB ICC精确转换，取每块中心横向5点均值。模拟输入由Sony码值经unity-WB、ITP和SSCS生成，并与Edit PT实采逐值核对。训练／验证／独立测试划分固定，独立测试不参与求解和候选选择。

先拟合Gamma灰阶明暗，再拟合CC1／block13色彩并联合微调；PC补偿参加压缩前整体优化。参数平滑约束参数和曲线本身，输出连续性检查实际颜色输出，两者独立。连续性探针只依赖输入，覆盖模拟前端和pre-matrix输入的暗部曝光、色相、饱和度局部三点；通过Lab a*b*二阶差分、输入自身曲率容差及RGB局部放大惩罚，抑制色度折返与跳变。相同目标进入CPU/GPU各原生阶段、整数参数验收和最终网格优化，不以浮点损失下降代替实际整数目标下降。

最终405节点网格直接拟合目标图，并与固定原生参数一起评估；3×5×9×9系数为−64..63整数。BIN只写CC1、block13、Gamma和网格，不额外写入PC补偿网络、响应模型或照片侧平滑阶段。新UI默认连续性30；历史请求缺失该字段仍按0解析，保留旧任务身份。

本次12项为AS、CC、EBB、ET、NC、NH、PV、RA、VN、理光正片、理光负片、Portra400NB。原始目标图片及运行目录不分发，配置、设置与导出来源散列公开。

连续性30高精度NC的单场景RAW对照中，带网格平均ΔE00由3.012454降为2.736027，底部纸箱区域由3.905534降为3.549991；部分RGB指标及不带网格结果退步，不能声称所有指标改善。该NC对照是独立先行任务，不冒充新版12项的实拍验证。详见[数值报告](../publication/4.34/NC_comparison_report.json)。

当前R5实拍v2响应只覆盖42/256单元，其他区域外推；任意RAW的空间前端仍是近似。训练完成与格式校验通过不代表机内成像或跨场景泛化验收。
