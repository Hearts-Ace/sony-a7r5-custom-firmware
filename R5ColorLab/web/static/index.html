所有新任务均采用原生分阶段拟合。开启后，原生参数与 PC 明暗曲线、染色曲线和网格残差交替训练。17×33×33 大网格经密集采样压缩为 5×9×9，与直接拟合小网格按验证表现选优，训练耗时会增加。完整 PC 补偿用于电脑预览；v4 BIN 需压缩为单一网格，验证 ARW 仅包含原生参数。
旧版模型使用 BT.601 暂定坐标、三线性插值、系数 / 256 和固定 3×3 响应；新版使用本次R5探针实拍拟合的坐标和颜色相关响应，本次留出RMSE 3.70；覆盖42/256单元，其他区域为外推。两者均可用于直接训练及压缩。切换后需重新训练／压缩；已有任务的指标、RAW 预览和导出继续使用其保存的模型。

训练权重 · 各组总损失占比
默认均为 1。新任务在每组内按任务绑定的基线亮度平衡阴影／中间调／高光（各占有样本分区的相同总权重），不改变 目标颜色；缺少的颜色仍需新色卡采集补充。数值表示每组总平方误差的相对权重，与样本数无关；同时用于原生参数、PC 网格与候选选优。提高某组权重可能牺牲其他颜色；灰阶专项曲线仍独立求解。
减少搜索，跳过全量高误差补训及反复PC交替；保留全部灰阶/色相阶梯、完整留出评估，最后重建补偿并压缩。关闭后使用完整精度流程。
评估次数越多通常越耗时，不保证颜色误差降低。新增任务先用 Gamma 拟合灰阶明暗，再用 CC1 / block13 拟合彩色，最后按设置权重联合微调。新任务默认使用 v4.5 5300K 色卡和 PT 模拟前端（由已验证颜色子链派生，新版独立 Edit 验收待完成）：保留正色、256 级灰阶和标准 24 色；随机色按明暗、色相和饱和度分层生成；Gamma 使用全部 128 个 RAW 节点，零点固定，第 129 点为独立导出端点；所选配置序号独立于机内原厂创意外观。
高级优化 · 精度优先
正在读取服务计算方式…
Apple Silicon 新服务默认使用 Metal GPU 训练。原生整数颜色运算使用 Metal 整数内核；目标 ICC 转换保留64位浮点8线程，RAW解码、参数建表、边界控制及最终验收由CPU执行。GPU与CPU使用相同目标和留出集；优化器不同，结果需比较。
v4精度版保留全部灰阶与24/16色相阶梯，按色相/饱和度/亮度分层粗训后执行全量精训及两轮高误差补训；完整留出集只做最终评估。v4 unity-WB 的99,372色块已与 Edit PT 实采核对；v4.5使用5300K补偿码值与派生上下文，不能当作新版实采验收。颜色训练链不含Edit空间锐化/Spica，任意RAW照片前端预览仍为近似。每阶段可设置1–2000次求解评估上限；达到上限与真正收敛会分别报告。
0 保留旧平滑策略；越高越抑制 Gamma 斜率突变、色相矩阵起伏，并加强 PC 曲线／网格平滑。参与训练、整数微调和候选选择，不模糊照片，不强制去除 LUT 原有染色。调整后需重新拟合；较高值可能增加色差，建议从 30 开始。
0 关闭。训练时检查连续明暗、色相和饱和度下的输出色度突变与过度放大，同时约束原生整数参数和最终网格。正式方案默认 30，独立于参数平滑；提高数值可能增加目标色差，调整后需重新训练。
确定性多起点搜索；动态权重仅根据训练误差在基础权重的 0.5–2 倍内调整。感知训练使用连续 Lab 色差，使用真实整数参数输出与浮点目标的RGB误差、连续ΔE00联合选优。量化后微调原生 CC1、96 个矩阵系数、127 个非零 Gamma 节点及 PC 7 位网格。设轮数／感知权重为 0 可关闭对应功能；最终选优始终使用固定基础权重，独立测试不参与训练。训练时间会显著增加。
可输入 0–131071 的整数；导出时必须不低于拟合后的第 128 点，否则拒绝生成 BIN，不截断前面的曲线。此点是固件独立端点，不在当前 RAW 颜色模型的 128 点中；修改不改变页面模拟图或 Edit 验证 RAW。已完成结果可在下方参数编辑器选择最后一点修改后加入导出集。
压缩训练：导入 LUT 或色卡目标图后训练原生参数与完整 PC 补偿，再蒸馏为单一网格；未导入新目标时，压缩当前已完成的明暗＋灰阶染色任务。
