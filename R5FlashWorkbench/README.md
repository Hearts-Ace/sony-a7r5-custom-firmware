本项目以魔改线方案为主，不再提供macOS刷写工作台。本目录仅保留补充打包提示词，供已经使用a7r5-rea破解相机、并持有其现有签名密钥的用户交给本机AI执行。

复制以下提示词：

```text

https://github.com/Hearts-Ace/sony-a7r5-custom-firmware
我的现有破解环境：
https://github.com/Liwenru88/a7r5-rea
```
