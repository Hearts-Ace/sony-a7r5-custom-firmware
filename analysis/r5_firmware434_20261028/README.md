# R5 4.34：创意外观动态图标与白色优先97

用户报告4.33自定义滤镜图标无法加载，本版以冻结4.33为功能基线，修正图标资源类别和动态图标来源。4.33及原始固件／首次备份保持。成品目标：research/r5_custom_lut/build_r5_4.34_icon_awb_20261028/BODYDATA.DAT，只有新release_tests/delivery_verified.json通过才确认本地交付。

4.33将0x021C6410当作图标，这是资源归属判断错误：该ID实际为英文Creative Look帮助文字。旧的原生回放只验证值传入sprite写入器，并未验证图片资源存在；其“普通图标”getter实际也是帮助字段。不能沿用4.33的图标通过结论。

4.34目标是自定义滤镜图标请求沿用真实Creative Look的当前外观状态；Creative Look为ST时自定义滤镜也显示ST。菜单名称仍为“自定义滤镜”，MID635和独立滤镜选择／保存／返回保持。按用户最新要求，不再追查主菜单左侧小logo；本版只修复动态图标取图，不认定该小logo属于类型标记。指令回放与资源类别核对不会代替机身LCD验收。

图标实现只在原厂取图入口0x1BD63B4转发MID635为MID1E6，20字节A64包装器重放原CMP后返回原厂分派。保留帮助字段+C，恢复图片fallback+60为sentinel；类型getter保持原生。既有22个其它编译对象与4.33逐字相同，RX63480、BSS136384。原厂PID690决定当前状态，私有滤镜选择不参与图标取图。

白色优先0x02A40000 +0x930为97（十六进制61），氛围+0x931保持−1，邻接00／06不改。白色局部主系数自动得到450，无需另改系数。该系数控制原厂后段分段修正，不能称为外置可见光／红外传感器权重。固定局部原始指令例子输出见color回执，实拍准确性和收敛需另外验证。

沿用4.33的12地区generic BK4模板及backup.sum保留方法，以原厂／strict4.04为打包基线，保留既有FL2／FL3动态B／A1／A2和R6可恢复ST照片CC1／block13 A1。Gamma与其余颜色参数保持；模板与4.33只应在AWB白色字节及其BK4／backup.sum校验发生差异。没有个人设置镜像覆盖或新增运行时强制写回。

本目录保留新的源绑定、原生参数／菜单／Fn回放及最终DAT独立校验。固件候选的版本为4.34／BCD3404；CP逐字保持423，沿用422网格生命周期。所有当前回执绑定新AP与实际源散列，不挪用旧AP测试回执。
