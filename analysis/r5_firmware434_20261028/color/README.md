# 4.34 R6 ST与AWB默认参数

本目录供新SD固件包的全部地区BK4模板合并使用。`color434.py`只修改属性内三个范围，不修改CP，也不生成个人设置镜像。

| 属性 | 范围 | 内容 |
|---|---|---|
| 0x02A40000 | +0x930，2字节 | 白色原厂88→97（4.33为112）、氛围−24→−1；+932/+933仍为0／6 |
| 0x02A40001 | +0x1250，48字节 | R6 ST三组CC1，转换成R5的B／A1−B／A2−B表示 |
| 0x02A4000D | +0x2A0，192字节 | R6 ST block13 A1全部16槽；B／A2和bank尾保留R5 |

三个属性在原厂12地区模板中逐字节相同，属性attributes均为0x8。原生SD升级迁移使用新模板的这些值；完整模板、backup.sum、打包及原生迁移验证由`../preservation/`处理。本模块本身不完成升级。

`color434_verified.json`绑定现4.32／4.33继承的实际CP（SHA256 `8b38e753f34b1667d79b69079d911b9e6595f1ce1b873cb8e014437c6b4c494d`）。63组CC1原始读取／运算、320组完整原生矩阵读取、336组完整AWB修正回放通过。ST照片profile0消费新CC1和A1；矩阵B／A2保持，测试的其它正常外观／ST视频参数保持。标准AWB的112组输入输出／跟踪值保持；两个被调优先级均有输入实际改变原生输出。白色97例：内部输入[18000,12000]，原厂88输出[17098,12718]，97输出[17302,12557]；有效系数为450，4.33的112对应480。

CC1测试的调整子服务只注入声明的向量；已安装的CC1自定义参数选取钩子与原始运算执行。矩阵与AWB没有helper桩。Unicorn在沙盒内触发SIGILL后，同一离线验证在获准的沙盒外运行；没有相机、串口或USB操作。

`integrated_templates_check.json`另对preservation生成的12份模板独立解析：三范围与供体精确相同，AWB61ff0006正确，ST矩阵B／A2／尾192字节及CC1尾16字节保持，BK4校验通过。与冻结4.33的12份模板逐字节比较，只允许AWB+930的112→97及第二BK4段校验变化；CC1／block13整属性完全相同，backup.sum仅12项CRC改变，因此R6 ST及FL2/FL3不被覆盖。`source_bindings.json`列出主构建manifest需显式绑定的源／验证依赖，含R6两片段和报告、当前／原厂CP、R5／FX2模板、原始AWB回放和输入属性、BK4／CPU辅助代码及固定上游四个模块。

限制：

- RAW只允许恢复ST照片bank0；ST视频profile21映射bank1，本次不修改。原本引用bank0的其它场景／别名自然共享变化，不另改映射。
- R6原厂BK4未提供；使用的是从RAW精确恢复并转换为R5格式的值。
- Gamma前128点、Knee／YGain及公共打包值与R5相同，沿用R5原生完整记录。不能由RAW恢复第129点、block13 B／A2、尾部或指针，未填造这些数据。
- 回放为人工状态／校准输入，未使用真实逐帧AWB统计。AWB参数是后段修正系数，不代表硬件传感器融合权重，也不保证具体画面改善。
- 后续仍需区分DAT离线核验、设备升级后回读、正常启动与实拍验收；模板验证不能代替后三者。
