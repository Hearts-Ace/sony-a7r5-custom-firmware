# Canon 十二款单滤镜（2026-11-18）

本目录包含 AMD RX 7900 XTX 队列第一批已完成的 12 款 Cobalt Canon v4.0 滤镜：Autumn Hues、Clear、Emerald、Faithful、Fine Detail、Landscape、Monochrome、Neutral、Nostalgia、Portrait Snapshot、Portrait Studio 和 Portrait。

每份 BIN 仅含槽 1，v4 格式，2580 字节；同名 JSON 是可编辑配置。可通过[在线资源库](https://hearts-ace.github.io/sony-a7r5-custom-firmware/#filters)选择任意滤镜加入资源栏，与其他滤镜合并下载，最多 12 款。

本批使用 `r5-paired-20261117-asymmetric-perceptual` 网格响应、ROCm float32 求解和 CPU 原生整数/FMA 验收。逐款状态为 `done`，叠加审计中 BIN 解码重编译、CPU 回放及父文件不变检查通过。未加去毛刺，未加 20% 轨迹权重调整，尚未实机验收。训练 TIFF、中间产物及远程路径不在本公开目录中。
