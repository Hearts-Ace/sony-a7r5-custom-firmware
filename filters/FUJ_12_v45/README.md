# 最新十二款滤镜（2026-11-14）

使用最新共享坐标多来源重拟合算子训练的两批参数合并，顺序：AS / CC / EBB / ET / NC / NH / PV / RA / VN / RP（理光正片）/ RN（理光负片）/ P400（Portra400NB），槽1–12。

下载 [R5NATIVE.BIN](R5NATIVE.BIN)，按所用固件支持的 BIN v4 导入流程加载。BIN 为 v4，29,552 字节，SHA256：`300a2f5acad8b11038ac4c74394d9d8b304d2f4ff3208558731d5de3801610d5`。

富士九款不加去毛刺；后三款已尝试去毛刺，但未接受整数修补。合并未改变各槽参数；编解码回环和来源逐槽一致性通过，未实机验收。
