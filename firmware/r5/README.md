# R5 4.65：滤镜参数交接候选

从官方 R5 4.00 输入构建，保留自定义滤镜、FL2/FL3、声音导入、Fn、自定义比例与裁切、取景和照片回放。SD 导入仍为整包校验后写入 eMMC，普通切换只读请求的单条滤镜。

AP 准备一个请求后让对应原厂 E4 任务接管，颜色值原样保留；CP 在原厂设置锁外准备数据，在原厂颜色接收路径发布。新旧任务可短暂各持一代参数；关闭撤销当前选择，已退役内容在最后一个原厂引用归还后由控制路径释放。单代 15,352 B，最多三代，未预加载滤镜库。固定对象的所有最后使用点尚未实机确认，不能保证关滤镜后立即全部释放。

此开发树可生成标明未实机验证的候选。封包继续核对原厂前像、组件身份、分区和签名；引用归属检查的通过与待验证项记录在验证回执。没有模拟放大切换或宣称修复机身卡死。源码、证据和已知限制的入口见 [4.65 验证记录](../../../../analysis/r5_owner_submit465_20261115/README.md)。
