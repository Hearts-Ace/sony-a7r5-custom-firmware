# 4.56 裁切与所参考 R5 项目的最小修改复核

结论：当前裁切实现的范围合理，符合本次需求下的最小修改原则。没有发现需要为此次 PT 改动进一步扩大裁切范围的证据；本轮保持裁切代码和组件字节。此结论是源码、补丁范围和既有离线证据复核，尚不能替代当前 4.56 的实机拍摄、编码和回放验收，也不声称它是所有可能实现中绝对最少的字节数。

参考为用户当时提供的 `custom-aspect-ratios.zip`，SHA256 `43d492427b9d1b7fce40ef5edf20668029e1261681d20babce2546e53936c123`，规范提取在 `analysis/r5_aspect456_20261110/reference/custom-aspect-ratios/`。参考 README 的当前分支为 R5 4.22，后来有 4.23 V2 联合测试；这些是参考方记录，不是本机安装或验收证据。参考同为 Sony R5 原厂内容 4.00。4.56 的内容基线仍为本项目冻结 4.55。

直接逐文件比较 13 份当前编码/元信息/回放源码：`crop_core.c/.h`、`avcam_jpeg.S`、`avcam_thm.S`、`avcam_heif.S`、`mpr_jpeg_metadata.c` 和 `mpr_heif.S` 共 7 份与参考逐字一致。其余 6 份差异集中于 RAW 预览尺寸来源、RAW 专用回放字段、精确匹配门和移除旧比例表。完整散列及差异在 `crop-source-comparison.json` 和各 `*.reference.diff`。

AP、CP、AVCAM、MPR 四组件分别承担菜单/冻结与显示、照片 task 与 JPEG view、HEIF/共享辅助 view、文件声明与解析；从消费者看，修改四组件有实际理由。仅改菜单或 CP 尺寸不能闭合 HEIF、RAW 预览声明和回放。原厂非目标尺寸/格式和其他 descriptor/actor 的回退保留；原有 PNG/文字资源和 Fn 生命周期按各源锁/回执核查，不为 PT 引入新资源。

本轮新 PT AP 通过逐项逆还原精确回到原最终 4.56 AP，旧裁切全部字节保持；CP、AVCAM、MPR 和 70 资源保持。原来的最终 AP 批量裁切/Fn/回放重跑被自动审批拒绝记录保留，本轮没有把旧回执重新标成新指令执行。当前 JPG/HEIF 硬件编码、完整 ARW 解码、LCD 和实际切换速度仍需设备验收。
